О проекте

Сайт Big Rental Astana создан как учебный проект по основам веб-разработки. Проект состоит из нескольких связанных HTML-страниц и посвящён сервису аренды профессиональной фото- и видеотехники в Астане.

На данном этапе сайт использует только HTML. CSS и JavaScript пока не используются. Поэтому оформление страниц остается стандартным, а основное внимание уделяется структуре документа.

Структура HTML

Для организации страниц используются семантические элементы: <header>, <nav>, <main>, <section>, <article> и <footer>. 

<section>
    <h2>Камеры Sony</h2>

    <article>
        <h3>Sony FX3</h3>
    </article>
</section>

Работа с файлами

HTML-файлы создавались и редактировались в Visual Studio Code. Для сохранения файла используется Command + S.

После сохранения HTML-файл можно открыть напрямую в браузере.
