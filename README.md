# Big Rental Astana

Semester project for the Introduction to Web Technologies course.

The website is based on Big Rental Astana, a camera and video equipment rental service in Astana.

## Assignment 2

Assignment 2 continues the same project from Assignment 1.

The main focus of this stage is CSS styling, selectors, the cascade, Flexbox, Grid, positioning, float and clear, spacing, typography, and layout.

## Project structure

- `index.html` — home page and company information
- `equipment.html` — equipment categories
- `cameras.html` — Sony camera catalog and rental prices
- `lenses.html` — Sigma lens catalog and rental prices
- `rental.html` — rental request form
- `cart.html` — demonstration rental cart
- `login.html` — demonstration sign-in page
- `signup.html` — demonstration registration page
- `colophon.html` — information about the project
- `css/base.css` — shared styles used across the website
- `css/arnur.css` — personal Assignment 2 stylesheet
- `images/` — project images

## CSS features

The project demonstrates:

- type, class and id selectors
- descendant, child and adjacent sibling selectors
- attribute selectors
- pseudo-classes and pseudo-elements
- CSS cascade and specificity
- Flexbox
- CSS Grid
- static, relative, absolute and fixed positioning
- float and clear
- multiple centering techniques
- colors, typography, spacing, borders and box model

## Current functionality

The website uses HTML and CSS.

JavaScript, databases, real authentication and server-side processing are not implemented yet.

The login, sign-up, cart and rental forms are demonstration interfaces only.
