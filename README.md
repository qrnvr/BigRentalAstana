# Big Rental Astana

This project was created for Assignment 1 of the Introduction to Web Technologies course.

The website is based on Big Rental Astana, a real camera and video equipment rental service in Astana.

## Project structure

- `index.html` — home page
- `equipment.html` — equipment categories
- `cameras.html` — Sony cameras
- `lenses.html` — lenses
- `rental.html` — rental form
- `colophon.html` — information about how the website was created
- `images/` — project images

## Technologies

- HTML
- Visual Studio Code
- Git
- GitHub
- Google Chrome

## Current stage

This is the first version of the semester project.

The website currently uses only HTML. CSS, JavaScript, databases, authentication, and server-side processing are not implemented yet.

The rental form is currently a demonstration form and does not save or send data.
